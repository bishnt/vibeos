# Engineering starter projects

- `spice/`: RC low-pass filter. Run `ngspice rc_lowpass.cir` and look at the gain plot.
- `verilog/`: 4-bit counter with a testbench. Run `make`, then open the waveform in GTKWave.
- `python/`: Bode plot of the same RC filter using SciPy. Run `python3 bode.py`.

Copy a folder and change it. Nothing here is special.
