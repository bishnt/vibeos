VibeOS

A Linux desktop in a browser tab.

VibeOS is a Debian desktop built for engineering students. Circuit simulation, Verilog tools, embedded toolchains and Python are already installed, and it runs on any device with a browser.

Launch desktop Open the calculators

The first load can take up to a minute while the machine wakes up.

It asks for a password
You enter it once the desktop connects. Ask whoever shared this link if you don’t have it.
Everyone shares one screen
Anyone connected sees the same desktop, so close your windows when you’re done.
Fullscreen and clipboard
Use the side panel in the desktop to go fullscreen or paste text from your own computer.
Built on Debian trixie with XFCE.
